# Layers (feature 12) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** User-defined layers, Visio-style: create, rename, delete, show/hide, lock, set the active layer, and move the selection to a layer. Hidden layers still count in every analysis.

**Architecture:**
- **Model:** `state.layers` is a list of `{ id, name, visible, locked }`. Every element and flow carries a `layerId`.
- **Loading and saving:** all loads go through `normalizeSession`, which validates layers, defaults to a single "Main" layer, and repairs unknown `layerId`s to `'main'`. Undo snapshots (`serializeModel`) and JSON export include `layers`.
- **Hiding:** a post-render pass hides the DOM of items on hidden layers, so the render code itself stays untouched. Flows are also hidden when either end is hidden. Line jumps and the minimap skip hidden items.
- **Selection:** one rule, applied in `refreshAppViewVisualWorkspace`, drops hidden or locked items from the selection. That blocks selecting, dragging and deleting them, whatever path selected them.
- **New items:** they get the active layer through `stampLayers()`, which runs before every undo point and every render.
- **UI:** a "Layers" accordion section in the left column, built with `createElement` (no `innerHTML`).

**Tech Stack:** Vanilla JS in `threat-tiger.html`, Bootstrap 5 and Bootstrap Icons, Playwright in Edge.

**Spec:** `docs/superpowers/specs/2026-11-09-diagramming-and-attack-paths-design.md` (section "12. Layers")

## Global Constraints

- Default layer `{ id: 'main', name: 'Main', visible: true, locked: false }`. Main cannot be deleted. At most 50 layers. Names are trimmed text, at most 60 characters; an empty name becomes "Layer N".
- Hidden layers are not drawn and not selectable but **still count** in threat analysis, suggestions, model checks, insights and the register. Locked layers are drawn but cannot be selected, moved, resized or deleted from the canvas.
- PNG export and print show what is visible. JSON export includes everything.
- Each layer action (add, rename, delete, show/hide, lock, set active, move selection) is one undo step through `logEvent`, except "set active", which is a view state: it is saved as `state.activeLayerId`, with no undo step.
- Imported layer data is untrusted: validate ids (`/^[\w-]{1,40}$/`) and names (text only), and add a layer-name case to `tests/xss.spec.js`.
- Single file, `npm run sync`, lint and full suite green, CHANGELOG, README and Help updated. No version bump, no push.

## Review Focus

1. **A layer is deleted that holds the active layer or the selection:** the active layer falls back to Main, the selection is kept (the items move to Main), and undo restores the layer and its items' `layerId`. Test in Task 3.
2. **Hidden ends:** a flow whose source is on a hidden layer is hidden too, even if the flow's own layer is visible; showing the layer again brings both back. Test in Task 2.
3. **Hostile import:** duplicate layer ids, a layer named `<img src=x onerror=alert(1)>`, 200 layers, a `layerId` pointing nowhere, and a non-list `layers` all load safely: layers capped at 50, the name rendered as text, unknown ids moved to Main. Test in Task 1 and the XSS suite.
4. **Undo across layer changes:** hiding a layer, then undo, shows it again; a node created on layer B, then undo and redo, comes back on layer B (not on whatever layer is active at redo time). Test in Task 1/3.
5. **Locked plus keyboard:** with a node selected on an unlocked layer and another on a locked one, select-all style paths, arrow-key moves and Delete never touch the locked one. Test in Task 2.

Test: `tests/layers.spec.js` (create); extend `tests/xss.spec.js`.

**Interfaces — Produces:**
- `DEFAULT_LAYER = { id: 'main', name: 'Main', visible: true, locked: false }` and `MAX_LAYERS = 50`.
- `normalizeLayers(raw, ctx) -> layers[]`:
  - Keeps plain objects with a valid id; drops duplicates; caps the list at 50.
  - The name goes through `toText`, is trimmed to 60 characters, and falls back to `Layer N`.
  - `visible` is true unless `=== false`; `locked` is `=== true`.
  - Main is always present and first: an existing `main` entry is moved to the front, or a default one is inserted.
  - Warns through `ctx.warn` on dropped entries.
- In `normalizeSession`: `session.layers` comes from `normalizeLayers(raw.layers)` (a non-list warns and is treated as empty). Every element and flow whose `layerId` is not among the layer ids gets `'main'`. `session.activeLayerId` is `raw.activeLayerId` when it exists, otherwise `'main'`.
- `app.stampLayers()`: any element or flow with no `layerId` gets `this.state.activeLayerId` (or `'main'`). It is called at the start of `logEvent` and of `renderSvgDiagramElements`.
- `serializeModel` adds `layers`; `applyModelSnapshot` restores it through the existing `Object.assign`. The export payload adds `layers` and `activeLayerId`.

  await setup(page, []);

### Task 2: Hiding, locking, selection rule

**Files:** Modify `threat-tiger.html`:
- `renderSvgDiagramElements`: the post-render pass;
- the line-jump block: skip hidden flows;
- `renderMinimap`: skip hidden elements;
- `refreshAppViewVisualWorkspace`: the selection rule;
- the node `mousedown` and `click` handlers: return early for locked or hidden items.

Test: `tests/layers.spec.js`.

**Interfaces:**
- **Consumes:** Task 1.
- **Produces:**
  - `app.layerOf(item) -> layer` (Main if unknown).
  - `app.isItemVisible(item)`: elements need their layer visible. Flows need their own layer visible **and** both ends visible.
  - `app.isItemLocked(item)`: the item's layer is locked.
  - `app.applyLayerVisibility()`:
    - After the core render, sets `display: none` (class `layer-hidden`) on every `[data-id]` and `[data-flow-id]` node in the canvas SVG whose item is not visible.
    - Flow labels and handles are covered when they carry `data-flow-id` or `data-id`. Add the attribute where it is missing.
    - Adds class `layer-locked` (`cursor: not-allowed` on hover) to locked items.
  - `app.filterSelectableSelection()`:
    - Removes hidden or locked ids from `selectedElementIds`, and clears `selectedFlowId` when that flow is hidden or locked.
    - It is called first thing in `refreshAppViewVisualWorkspace`.
